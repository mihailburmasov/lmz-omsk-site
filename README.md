# Сайт ООО «ЛМЗ» — литейно-механический завод, Омск

Многостраничный корпоративный сайт на чистых HTML5 + CSS3 + vanilla JS (без
фреймворков и сборщиков) с формой обратной связи на PHP. Разворачивается
копированием папки на любой shared-хостинг с PHP 7.4+.

## Структура проекта

```
lmz-omsk/
├── index.html                 Главная
├── uslugi/                    Хаб услуг + 6 подстраниц (литьё по металлам/технологиям)
├── vozmozhnosti/               Технологические возможности
├── o-zavode/                   О заводе
├── raboty/                     Галерея работ
├── kontakty/                   Контакты
├── politika-konfidencialnosti/ Политика конфиденциальности (152-ФЗ)
├── soglasie-na-obrabotku-dannyh/ Согласие на обработку персональных данных
├── 404.html
├── assets/
│   ├── css/style.css          Все стили (секции размечены комментариями)
│   ├── js/                    config.js, main.js, form.js, gallery.js
│   ├── img/                   favicon-набор, og-image, SVG-плейсхолдеры фото
│   └── fonts/                 Manrope (self-hosted, woff2, OFL-лицензия)
```

## Как развернуть на хостинге

1. Скопируйте содержимое папки на хостинг (корень домена или нужную подпапку).
2. Хостинг должен поддерживать PHP 7.4+ и модуль `mod_rewrite` для `.htaccess`
   (redirects, security-заголовки, кэширование).
3. Откройте `mail/config.php` и заполните:
   - `to_email` — куда присылать заявки (сейчас пусто — письма не уйдут, пока не заполнено);
   - блок `smtp` — данные почтового ящика хостинга (host/port/username/password);
   - `antispam.allowed_origins` — домен(ы) сайта, например `https://lmz-omsk.ru`.
4. Замените домен-заглушку `https://lmz-omsk.ru` на реальный домен клиента —
   он используется в `<link rel="canonical">`, Open Graph, JSON-LD и
   `sitemap.xml`/`robots.txt`. Эти значения генерировались из общего списка
   в момент сборки сайта; при смене домена проще всего заменить строку
   `https://lmz-omsk.ru` во всех `*.html`, `robots.txt` и `sitemap.xml`.
5. Проверьте отправку тестовой заявки (см. чек-лист ниже).

## Единая точка правды по контактным данным

- **Фронтенд:** `assets/js/config.js` — телефон, e-mail, адрес, ссылки на
  мессенджеры. Все шаблоны читают эти значения через `data-site-*` атрибуты
  и `main.js`, так что достаточно поменять значения один раз здесь.
- **Бэкенд:** `mail/config.php` — получатель писем, SMTP, антиспам, лимиты
  вложений. У фронтенда и бэкенда нет общего рантайма, поэтому оба файла
  синхронизируются вручную при изменении контактов.

Если ссылка на мессенджер (Telegram, MAX) или e-mail оставлены пустыми
(`''`), соответствующая кнопка автоматически скрывается на всех страницах —
ничего дополнительно менять в HTML не нужно.

## Как подключить Яндекс.Метрику / Google Analytics

В каждой странице в `<head>` и перед `</body>` оставлены HTML-комментарии
`<!-- Яндекс.Метрика: ... -->` и `<!-- Google Analytics (GA4): ... -->` —
вставьте туда стандартный код счётчиков. После установки Метрики задайте
глобальную переменную:

```html
<script>window.YM_COUNTER_ID = 12345678;</script>
```

`assets/js/main.js` уже отправляет события через `window.trackEvent(name)`
для целей: `form_submit` (успешная отправка формы), `click_phone` (клик по
номеру телефона), `click_messenger` (клик по иконке мессенджера),
`map_open` (клик по превью карты). Останется завести одноимённые цели в
Метрике/GA — код их уже отправляет.

## Замена фото-плейсхолдеров

Реальных фотографий пока нет — их место занимают сгенерированные SVG с
подписью, что должно быть на снимке, и рекомендуемым размером. Все
плейсхолдеры лежат в `assets/img/placeholders/`.

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `hero-cover.svg` | Главная, фон первого экрана | 1600×900, до ~250 КБ (webp) |
| `gallery-*.svg` (8 файлов) | Главная и «Наши работы» — плитки галереи | 800×600 |
| `usluga-chugun.svg`, `usluga-stal.svg`, `usluga-bronza-med.svg`, `usluga-alyuminiy.svg`, `usluga-pgs.svg`, `usluga-kokil.svg` | Соответствующие страницы услуг | 1000×700 |
| `zavod-tsekh.svg` | «О заводе» | 1200×800 |
| `zavod-territoriya.svg` | Запасной кадр (пока не используется — можно поставить на страницу «О заводе» или в галерею) | 1200×800 |
| `vozmozhnosti-cover.svg` | «Возможности» | 1200×700 |
| `og-image.png` | Общая заглушка Open Graph (уже растровая, сгенерирована) — по желанию можно заменить на фирменную картинку с реальным фото | 1200×630 |

### Как заменить плейсхолдер на реальное фото

1. Подготовьте фото в `.webp` (основной формат) и `.jpg` (фоллбэк) нужного размера.
2. Замените `<img src="/assets/img/placeholders/ИМЯ.svg" ...>` на:
   ```html
   <picture>
     <source srcset="/assets/img/ИМЯ.webp" type="image/webp">
     <img src="/assets/img/ИМЯ.jpg" alt="Осмысленное описание" width="W" height="H" loading="lazy">
   </picture>
   ```
3. Для первого экрана (`hero-cover`) добавьте `fetchpriority="high"` вместо `loading="lazy"`.
4. Впишите осмысленный `alt` с ключевым словом (например,
   «Литьё чугуна на заказ в Омске — заливка формы»).

## Форма обратной связи

- Две модификации: полная форма «Рассчитать стоимость» (на всех основных
  страницах, включая подвал/якорь `#zayavka`) и всплывающий попап
  «Заказать звонок» (кнопка в шапке/подвале открывает `#modal-callback`).
- Отправка — через `fetch` на `mail/send.php` без перезагрузки страницы;
  форма также работает без JS (обычный POST) как запасной вариант.
- Антиспам: honeypot-поле, минимальное время заполнения (3 сек), лимит
  отправок с одного IP в час (файловый счётчик в `mail/log/ratelimit/`),
  мягкая проверка `Origin` (включается, когда домен указан в конфиге).
- Заявки логируются в `mail/log/leads.csv` независимо от того, ушло письмо
  или нет — так лид не потеряется при проблемах с почтой. Папка `mail/log/`
  закрыта от прямого доступа через `.htaccess`.
- Вложения: pdf/jpg/jpeg/png/dwg/zip, до 10 МБ, проверяются по расширению и MIME.

## Дизайн-система

Все переменные заданы в `:root` в начале `assets/css/style.css`: палитра,
шкала отступов (4/8/16/24/32/48/64/96), радиусы, тени, анимации. Шрифт —
Manrope, подключён локально (`assets/fonts/*.woff2`, кириллица и латиница
отдельными `@font-face` с `unicode-range`), без Google Fonts и внешних CDN.

Брейкпоинты: 480 / 768 / 1024 / 1280 px, mobile-first. Секции появляются
плавно при прокрутке через `IntersectionObserver` (класс `.reveal`), с
уважением к `prefers-reduced-motion`.

## Локальная разработка

PHP-обработчик формы требует локальный PHP-сервер:

```bash
php -S localhost:8000
```

Для статических страниц подойдёт любой раздающий текущую папку сервер —
например, `npx http-server` или `python -m http.server`.
